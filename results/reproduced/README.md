# Reproduced results

This folder is empty on purpose. No experiment has been run for this repository.

After you train models, `scripts/collect_results.py --split random|plant` writes
`reproduced_<split>_split.csv` here. It places your numbers next to the values reported in the paper.
Keep these files separate from `results/paper_results/` and `results/tables/`, which hold only
paper-reported values.
